How to use this site

  1. Read the chapter. Definitions are boxed and comparisons are in tables, because that is the shape most exam questions take. Skim the table of contents first so you know what is coming.
  2. Drill that one chapter. Hit the “Test this chapter” button at the bottom of the page, or use quiz.html?chapter=4. Use Practice mode — the multiple choice is only there for speed, the written answer that appears underneath is the part you actually learn from.
  3. Run a full mock exam. Once the individual chapters feel solid, choose All chapters, Mock exam mode, 50 questions and a timer. The results screen breaks your score down by chapter so you can see which one is dragging you under.
  4. Go back to the weak chapter and repeat. Use “Retry incorrect only” on the results screen to re-sit just the ones you got wrong.
