Chapter 1

Introduction to the Internet and the Web

Short chapter, and almost entirely definitions. The one idea that carries through the whole module is the distinction between the internet (the physical network) and the web (one of the services running on it).

1. The internet and the web

Internet
The physical network that connects millions of computers together globally and allows them to communicate.
World Wide Web (WWW)
A way of accessing information over the medium of the internet. A second, equally acceptable definition: a collection of web pages available on the internet.

2. The difference between them

The internet is infrastructure. The web is content delivered over that infrastructure. The internet is the physical network that lets computers in different places communicate; the web is the collection of websites and web pages that users reach through the internet using a web browser.

The internet compared with the web
InternetWorld Wide Web
What it isA physical network of connected computersA service that runs on top of that network
Made ofCables, routers, servers, protocolsWeb pages and websites linked by hypertext

Can you have the internet without the web?

Yes. The web is only one of the services that runs over the internet. We reach websites through the internet, but the internet is used for plenty of things that are not web browsing — messaging apps such as WhatsApp, email, file transfer, online gaming and video calls all use the internet without touching the web. Remove the web and the network underneath it still works.

The reverse is not true: you cannot have the web without the internet, because the web has nothing to travel over.

3. Who owns the internet?

No one owns the internet. It is mostly funded by private and public IT companies. There is no single owner, no single operator, and no central authority that can switch it off.

4. Origins and standards

  • The internet began with the ARPANET project in 1969.
  • The standards and guidelines for the web are published by the World Wide Web Consortium (W3C).

5. Core terms

TCP/IP — Transmission Control Protocol / Internet Protocol
A set of protocols developed to allow cooperating computers to share resources across a network.
URL — Uniform Resource Locator
The unique address of every web page on the internet.
Web browser
Application software that allows us to view web pages.

6. Services on the internet

The internet provides many services. Among them:

  • Communicating — messaging, email, voice and video calls
  • Searching — finding information through search engines
  • Education / e-learning
  • Online shopping
  • Digital banking
  • Social networking

7. Why internet technologies matter

Internet technologies have become central to ordinary daily life. Almost everyone now relies on them for work, study, messaging, phone calls, banking, shopping, gaming and browsing. What was once a specialist research network is now the default medium for communication and commerce — which is exactly why the privacy and security material in Chapter 4 matters so much.
